Katalog Kemampuan

Daftar Tool Calling ("Tangan & Kaki")

Modul Python lokal yang dapat dipanggil oleh LLM secara mandiri untuk berinteraksi dengan sistem PC.

📊
get_system_status
Aman (Read-Only)

Membaca penggunaan persentase CPU, kapasitas memori RAM (total, used, free), sisa penyimpanan harddisk, status persentase baterai laptop, dan uptime PC.

Contoh ucapan di Telegram:
"Berapa sisa RAM dan status baterai PC sekarang?"
📸
take_screenshot
Aman (Visual)

Menangkap gambar seluruh layar monitor PC via modul Pillow / ImageGrab, menyimpannya sementara, dan langsung mengirimkan file gambar tersebut ke chat Telegram Anda.

Contoh ucapan di Telegram:
"Tolong screenshot layar monitor dong, mau cek download-an."
🌐
open_application_or_url
Aman

Membuka tautan web di browser default (Chrome/Firefox/Edge) atau meluncurkan file / software aplikasi di PC (Windows startfile, macOS open, Linux xdg-open).

Contoh ucapan di Telegram:
"Buka video YouTube lo-fi di PC" atau "Buka kalkulator"
🔊
set_volume
Aman

Mengatur volume output audio speaker PC antara 0 (mute total) sampai 100 (maksimal). Mendukung Windows PowerShell, Linux pactl/amixer, dan macOS osascript.

Contoh ucapan di Telegram:
"Kecilkan volume speaker ke 20 persen sekarang"
🔔
send_desktop_notification
Aman

Memunculkan banner notifikasi pop-up (Toast Notification) di pojok monitor PC untuk memberi peringatan visual ke orang yang ada di depan PC.

Contoh ucapan di Telegram:
"Kirim notifikasi ke layar PC: Jangan lupa matikan kompor!"
💻
execute_command
Perhatian (Power Tool)

Mengeksekusi perintah terminal shell / cmd di PC dengan proteksi timeout (25 detik) dan proteksi filter kata kunci berbahaya (rm -rf /, format c:).

Contoh ucapan di Telegram:
"Cek daftar proses yang memakan memory: ps aux --sort=-%mem"
Panduan Praktis

Cara Pasang & Jalankan dalam 4 Langkah

Mudah dipelajari bahkan untuk pemula. Siapapun bisa membuat asisten AI PC pribadi dalam waktu kurang dari 5 menit.

1

Buat Bot Telegram & Catat Chat ID Anda

1. Buka aplikasi Telegram, cari bot resmi @BotFather, lalu kirim perintah /newbot.
2. Ikuti instruksi untuk memberi nama bot dan dapatkan HTTP API Token.
3. Cari bot @userinfobot di Telegram, klik Start untuk mengetahui angka User ID akun Telegram Anda (ini nomor whitelist keamanan Anda).

2

Dapatkan API Key LLM (100% Gratis)

Pilih salah satu penyedia LLM gratis dan cepat:
• Google Gemini Flash Lite: Buka aistudio.google.com, login dengan akun Google, lalu klik Get API Key.
• Groq Cloud API: Buka console.groq.com, buat akun, dan buat API Key baru (kecepatan token inference Groq mencapai 500+ token/detik!).

3

Clone Repositori & Pasang Dependencies di PC

Buka Terminal (Linux/macOS) atau PowerShell / Command Prompt (Windows) di PC Anda, lalu jalankan:

git clone https://github.com/atzartech-prog/miniagentlite.git cd miniagentlite pip install -r requirements.txt
4

Konfigurasi .env & Jalankan Agen

Salin file config.example.env menjadi .env dan masukkan token serta API Key Anda:

cp config.example.env .env # Edit isi .env menggunakan notepad atau nano python agent.py

Buka bot Telegram Anda di smartphone, klik Start atau ketik "Berapa sisa RAM PC saya?". Agen Anda langsung merespons dan mengeksekusi kontrol PC secara nyata!
